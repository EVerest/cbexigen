# ISO 15118-2 eMAID element-fragment EXI vectors.
#
# Reference bytes produced by Exificient (the EXI codec Josev uses), via
# iso15118.shared.exi_codec.EXI().to_exi(EMAID(id=..., value=...),
# Namespace.ISO_V2_MSG_DEF).  Exificient implements the EXI 1.0
# schema-informed element fragment grammar (section 8.5.3), which the eMAID
# element requires because its qname is bound to two distinct types
# (EMAIDType and eMAIDType) in the ISO 15118-2 schema set.
#
# Id lengths 1..6 are covered deliberately: each one shifts the character
# payload to a different bit offset, so a grammar that is right only at one
# alignment cannot pass the whole set.
#
